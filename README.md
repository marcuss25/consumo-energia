# Calculadora de Consumo Elétrico

![execucao](github-assets/codigo.png)

## Objetivo
Esse código foi feito para calcular o quanto um aparelho eletrodoméstico gasta por mês em kWh e em Reais. O usuário apenas informa o nome, a potência e a quantidade de horas que fica ligado por dia.  

## Tecnologias Utilizadas
<img src="https://cdn.jsdelivr.net/gh/devicons/devicon/icons/python/python-original.svg" width="20" alt="Python"/> Python     

## Fórmula para cálculo
Consumo Mensal(kWh) = (Potência(W) . Horas . 30) : 1000  

## Como testar
**É necessário ter o Python instalado no computador para executar.**

No VS Code
- abra a pasta do projeto
- clique no arquivo .py, depois clique em “Run” ou F5
- selecione “Run without debug”

No Terminal (com venv)
- abra o terminal na raiz do projeto
- digite “Python app.py” para rodar o programa

Caso não saiba configurar o venv [clique aqui](https://dev.to/franciscojdsjr/guia-completo-para-usar-o-virtual-environment-venv-no-python-57bo).
